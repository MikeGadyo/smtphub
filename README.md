# SMTPHub

Управление SMTP-серверами и резервной отправкой почты для MODX Revolution.

У каждого подключения свои логин, пароль, порт и шифрование. При ошибке соединения, TLS или авторизации SMTPHub пробует следующий сервер по списку. Неисправный сервер временно пропускается, а после паузы снова используется при очередной отправке, если доступен.

**Версия:** 1.0.0-beta2. **Автор:** mikegadyo. **Лицензия:** MIT.

## Требования

Целевые версии — MODX Revolution 2.8.x и 3.x. Требуются PHP 7.4+ с OpenSSL, mbstring и PDO MySQL, MySQL/MariaDB. Версия PHP должна также подходить установленному MODX. Интерфейс пакета — на русском языке.

## Установка

1. Скачайте `smtphub-1.0.0-beta2.transport.zip` из [Releases](https://github.com/MikeGadyo/smtphub/releases) и положите его в `core/packages/` сайта.
2. В менеджере пакетов MODX выполните поиск локальных пакетов и установите SMTPHub.
3. Откройте **Пакеты → SMTPHub**. Добавьте подключения вручную или нажмите **Импорт настроек SMTP**.
4. Укажите параметры провайдера, расположите серверы в нужном порядке и нажмите **Обновить** для проверки соединений.
5. Включите **SMTPHub** и нажмите **Сохранить настройки**.

При первой установке SMTPHub выключен. Для доступа к странице требуется право MODX `settings`.

## Управление

- Серверы используются сверху вниз. Перетаскивайте строки, чтобы изменить порядок; он сохраняется сразу.
- Значок питания включает и выключает сервер: зелёный — включён, серый — выключен.
- Меню **⋮**: редактирование, копирование, перенос в системные настройки MODX и удаление.
- **Обновить** проверяет включённые серверы без отправки письма. Результат с датой сохраняется в колонке **Доступен**. `*` означает, что параметры изменились после проверки.
- **Пауза после сбоя** — время пропуска неисправного сервера, по умолчанию 60 секунд. Резервный пробуется сразу после отказа основного.
- **Email отправителя** и **Имя отправителя** — необязательные поля для каждого сервера. Пустые сохраняют отправителя сайта; заполненный email заменяет адрес «От кого» и адрес возврата ошибок при использовании этого SMTP. Адрес для ответа (Reply-To) сохраняется.

Поля подключения, импорт и остальные действия описаны в [руководстве](TECHNICAL.md).

## Особенности

SMTPHub работает с общим почтовым сервисом MODX. Прямой `mail()` и отдельные почтовые библиотеки обходят пакет. Каждый SMTP должен разрешать выбранный для него адрес отправителя. Для одного общего адреса оставьте новые поля пустыми и разрешите этот адрес на всех серверах. Для разных ящиков укажите свой email в каждой записи.

Отправка синхронная. Если все серверы недоступны, она завершается ошибкой; очереди нет. После начала передачи письма пакет не повторяет его на другом сервере, чтобы избежать дубликатов. Проверка доступности не подтверждает доставку письма.

Для возврата к штатной отправке выключите SMTPHub и сохраните настройки. Пароли зашифрованы: для резервной копии сохраняйте базу вместе с `core/config/smtphub.key.php`.

Обновление сохраняет подключения и пароли. У существующих записей новые поля отправителя остаются пустыми.
